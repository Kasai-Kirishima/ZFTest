# Zero Football v90 — обновление

- Исправлена загрузка фотографий футболистов в карточках открытия паков: прямые фото подставляются сразу, а поиск изображения по Wikipedia получил тайм-аут и дополнительные варианты поиска страницы.
- Устранено зависшее состояние `pending`, из-за которого повторная попытка загрузки фото могла не запускаться. Пока фото загружается, портрет остаётся видимым.
- Экран результата открытия стал компактнее: отступы между карточками уменьшены, размер сетки и число колонок учитывают количество выпавших игроков.
- Уменьшено пустое пространство вокруг сетки; карточки остаются в пределах одного экрана без прокрутки. Анимация открытия сохранена.
- Изменений Supabase и SQL-миграций нет.
