# Zero Football v92 — заметки обновления

Обновление v92 не меняет структуру Supabase и не требует запуска SQL-миграции.

В релизе обновлена локальная игровая логика: платное продление контрактов удалено, замены пользовательской команды не выполняются автоматически, ограничения на недоступных игроков действуют при назначении и заменах, выносливость восстанавливается по реальному времени. Добавлены независимые спонсорские миссии и 50 фактов на экранах загрузки.

Существующие клубные данные сохраняются. Для восстановления выносливости старым сохранениям автоматически добавляется временная отметка; у игроков без сохранённой отметки отсчёт начинается с момента первого запуска новой версии.
