# Подключение Supabase — Zero Football v60

## Что уже подготовлено в игре
- Подключение Supabase JS v2 через CDN.
- Конфигурация проекта в `js/supabase-config.js`.
- Регистрация по email и паролю, вход и выход.
- Ручная загрузка локального сохранения в облако и ручное восстановление из облака.
- Локальный одиночный режим остаётся доступен без регистрации и интернета.

## Обязательный шаг в панели Supabase
1. Открой проект `wakhszvjzzhxyfezpkvl`.
2. Перейди в **SQL Editor** → **New query**.
3. Открой файл `supabase/001_cloud_saves.sql`, скопируй весь SQL и выполни его кнопкой **Run**.
4. Перейди в **Authentication** → **URL Configuration**.
5. Укажи адрес сайта Zero Football в **Site URL** и добавь его в **Redirect URLs**. Для локального тестирования добавь `http://localhost:8000/**`.
6. В **Authentication** → **Providers** проверь, что Email включён. Если включено подтверждение почты, после регистрации нужно перейти по ссылке из письма.

## Запуск локально
Из папки проекта запусти локальный HTTP-сервер, например:

`python -m http.server 8000`

Открой `http://localhost:8000`.

## Как пользоваться
1. Открой игру → Настройки → Аккаунт Zero Football.
2. Создай аккаунт или войди.
3. Нажми **Сохранить в облако**, чтобы отправить текущие локальные клубы.
4. На другом устройстве войди в тот же аккаунт и нажми **Загрузить из облака**.

Важно: пока синхронизация ручная. Загрузка из облака заменяет локальное сохранение целиком. Перед этим рекомендуется сохранить локальную копию. Не публикуй секретный `service_role` или secret key; в браузере используется только publishable key.
