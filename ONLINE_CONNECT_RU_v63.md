# Как подключить онлайн Zero Football

1. Открой проект Supabase, который уже использовался для v60–v62.
2. В Supabase открой SQL Editor → New query.
3. Выполни миграции по порядку, если ещё не выполнял их: `supabase/001_cloud_saves.sql`, `supabase/002_multiplayer.sql`, `supabase/003_quick_match_live.sql`. Если 001 и 002 уже запускались, повторять их не нужно. Для v62 нужна 003.
4. В Authentication → URL Configuration укажи адрес опубликованной игры в Site URL и добавь его в Redirect URLs. Для локального теста добавь адрес локального сервера, например `http://localhost:8000/**`.
5. Проверь `js/supabase-config.js`: Project URL и publishable/anon key должны соответствовать твоему проекту. Не вставляй `service_role` или secret key в браузерный код.
6. Опубликуй все файлы проекта на одном HTTPS-хостинге (например, Netlify, Cloudflare Pages или GitHub Pages). Открытие `index.html` как `file://` не подходит для стабильного онлайн-режима.
7. Открой опубликованный адрес на двух устройствах/в двух разных браузерах, создай два аккаунта и войди в игру.
8. Оба игрока должны иметь клуб с полным составом. Нажми «Найти соперника» на обоих устройствах почти одновременно. Если за 30 секунд соперник не найден, запускается бот.

Если регистрация проходит, но облачное сохранение выдаёт RLS error, не отключай RLS. Проверь, что пользователь вошёл, а `user_id` в записи равен ID из активной сессии Supabase.
