# Zero Football v95

Исправлено отображение срока отсутствия травмированного игрока: число матчей больше не дублируется в медицинском разделе. Например, вместо «Пропустит ещё 1 1 матч» отображается «Пропустит ещё 1 матч».

Изменение касается только интерфейса. Расчёт и списание оставшихся матчей травмы и дисквалификации не менялись. Миграция Supabase не требуется.
