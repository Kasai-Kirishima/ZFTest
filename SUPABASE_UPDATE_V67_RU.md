# Обновление Zero Football v67

## Файлы игры

1. Сохрани резервную копию проекта и локальных данных вне папки релиза.
2. Распакуй файлы v67 на тот же хостинг, заменив файлы предыдущей версии.
3. Не заменяй `js/supabase-config.js`, если в нём уже указаны URL и публичный ключ твоего Supabase-проекта.
4. Обнови страницу жёсткой перезагрузкой (Ctrl+F5).

## Supabase

Для работающей версии v66, где выполнены миграции `001`–`004`, требуется только новая миграция:

`supabase/005_v67_market_economy_fix.sql`

Выполни её целиком в Supabase → SQL Editor → New query. Она устраняет ошибку `zf_market_listings.is_duplicate NOT NULL` и сохраняет флаг повторной карточки при выставлении на рынок.

Для новой установки выполняй миграции строго по порядку: `001`, `002`, `003`, `004`, `005`.

Не отключай RLS и не используй `service_role`/secret key в браузере.

## Что изменено в v67

- Новый код `Reliz`: €50 млн и два трёхзвёздочных пака.
- Старые промокоды удалены из доступных кодов.
- Расходники команды стали заметно дороже; ежедневные, ежемесячные и долгосрочные задания получили увеличенные выплаты.
- Изображения паков добавлены в инвентарь и анимацию открытия.
- Добавлена возможность выбрать и открыть следующий пак прямо из окна открытия.
- Цены продажи карточек снова показываются диапазоном и случайно рассчитываются внутри него.
- Ручная жеребьёвка управляется выбором позиции участников в интерфейсе.
- Улучшены стили карточек инвентаря и соревнований.

## Важно

Локальная экономика не защищена серверным кошельком. Используй внутренние валюту и награды только внутри тестовой игры.
