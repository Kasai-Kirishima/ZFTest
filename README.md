# Zero Football — Release v67

Модульная браузерная футбольная игра. Интерфейс, стили, игровые данные и логика разделены по файлам. Сборка сохраняет существующие локальные клубы и подключение Supabase из `js/supabase-config.js`.

## Запуск

1. Распакуй архив на HTTPS-хостинг либо запусти локальный сервер из папки проекта: `python -m http.server 8000`.
2. Для локального запуска открой `http://localhost:8000`.
3. Не заменяй `js/supabase-config.js`, если в нём уже настроен твой Supabase URL и публичный ключ.

## Обновление Supabase

Для существующей установки v66, где уже применены миграции `001`–`004`, выполни только `supabase/005_v67_market_economy_fix.sql` через Supabase → SQL Editor → New query.

Миграция исправляет флаг `is_duplicate` в объявлениях трансферного рынка: заполняет прежние `NULL`, устанавливает безопасное значение по умолчанию и пересоздаёт RPC `zf_market_list` с защитой от `NULL` при добавлении записи.

Для новой установки применяй SQL-файлы по порядку: `001_cloud_saves.sql`, `002_multiplayer.sql`, `003_quick_match_live.sql`, `004_social_market_competitions_clans.sql`, `005_v67_market_economy_fix.sql`.

**Не отключай RLS и не помещай `service_role`/secret key в браузер.** Используй только публичный publishable/anon key.
