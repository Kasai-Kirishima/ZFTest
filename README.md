# Zero Football v75

Обновление поверх v74.

- Возвращена активация промокода в магазине паков.
- Сам код и описание награды нигде в интерфейсе не показываются: игроки могут найти его самостоятельно.
- Код `Reliz` по-прежнему активирует прежнюю награду: €50 млн и два пака Агентства ★★★.
- Исправления заданий, отображения евро, трансферов, турниров, кланов, лазарета и поддержки из предыдущих версий сохранены.
- Совместимость с текущими сохранениями и Supabase сохранена. Миграция БД не нужна.

Сохраняйте `js/supabase-config.js` при обновлении.


## v75
- Automatic bot substitutions with a real reserve bench and match-log commentary.
- Six penalty actions and expanded attacking/defensive free-kick choices.
- Pack opening now displays pack title, revealed players and all available actions clearly.
- Missing player stamina safely defaults to 100; new players start at 100.


## v75 — изменения

- Боты получили скамейку запасных и автоматически проводят до трёх замен примерно на 63–81-й минутах; замены появляются в хронике матча.
- Пенальти снова предлагают шесть вариантов действий. Штрафные расширены до восьми вариантов атаки или обороны.
- На экране открытия пака сразу видны название набора, список выпавших игроков, карточки и доступные действия.
- Отсутствующая выносливость теперь считается полной (100), новые игроки создаются с 100 пунктами; проверки матча больше не принимают пустое поле за ноль.
- Изменения не требуют новой миграции Supabase.
