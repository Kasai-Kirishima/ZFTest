# Zero Football v71 — обновление

Для v71 новая SQL-миграция Supabase не требуется.

Обновление добавляет интерфейс лазарета и дисциплинарных карточек, подробные диагнозы травм и более редкое возникновение повреждений. Сведения о травмах сохраняются в объекте игрока внутри существующего сохранения клуба.

При публикации замени файлы проекта файлами из архива. Не перезаписывай собственный `js/supabase-config.js`, если в нём уже настроены URL и ключ Supabase.
