# Обновление Zero Football v68

1. Сделай копию текущих файлов сайта у себя перед заменой.
2. Распакуй архив v68 поверх предыдущей версии, сохранив свой `js/supabase-config.js` с настройками проекта.
3. Очисти кеш браузера или открой игру в приватной вкладке, чтобы загрузился новый CSS.

## Supabase

Для v68 новая SQL-миграция не требуется. Версия использует существующую схему и RPC рынка из v67. Если ты ещё не применял миграцию `supabase/005_v67_market_economy_fix.sql`, сначала выполни её после миграций `001`–`004`.

## Изменения v68

- Лимит текста на эмблеме увеличен до 18 символов; длинный текст автоматически уменьшается, чтобы помещаться на эмблеме.
- Рынок и основные элементы вкладок адаптированы под узкие экраны телефонов.
- Каждый футболист запаса выводится отдельной карточкой для выставления.
- Условия трансфера: быстрый (80% оценки), стандартный (100%), максимальная цена (125%) и собственная цена.
- Игроки стартового состава остаются недоступны для продажи.
- Обновлено единое оформление карточек, форм, кнопок и разделов.
