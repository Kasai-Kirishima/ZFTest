# Zero Football v70 — обновление Supabase

Перед использованием новых функций выполни в Supabase SQL Editor файл:

`supabase/006_v70_market_filters_and_competition_delete.sql`

Миграция добавляет:
- поиск карточек на трансферном рынке по части имени или по точному совпадению;
- безопасное удаление собственных лиг и турниров;
- каскадное удаление участников, приглашений, матчей и результатов вместе с соревнованием.

Удалить чужое соревнование нельзя: сервер проверяет `auth.uid()` и владельца записи. Удаление своего клана уже выполняется существующей функцией `zf_clan_disband()` и отдельной миграции не требует.

Порядок миграций для чистой базы: `001` → `002` → `003` → `004` → `005` → `006`.
Для существующей базы v69 достаточно выполнить только `006`.
