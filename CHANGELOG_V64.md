# Zero Football v64

- Повторная карточка: игрок выбирает между продажей за половину обычной стоимости продажи дубликата и продлением контракта исходного футболиста на 5 дней.
- Инвентарь паков: выбор количества для открытия одного типа паков за раз; можно открыть сразу несколько, награды показываются одним экраном.
- Убрана отдельная вкладка мультиплеера и быстрый пункт мультиплеера на главной. Поиск соперника в разделе матча сохранён.
- Уменьшены лишние перерисовки онлайн-матча: обновления только при изменении состояния, polling реже и только когда открыт онлайн-матч/комнаты.
