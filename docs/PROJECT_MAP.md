# Карта проекта Zero Football v67

## Структура

- `index.html` — точка входа, порядок подключения стилей и игровых модулей.
- `css/` — базовая сетка, карточки игроков, тактическое поле, анимации, темы, адаптивность, онлайн-разделы и release polish v67.
- `js/app.js` — игровое состояние, аккаунты и клубы, матчи, пакеты игроков, экономика, интерфейс и обработчики действий.
- `js/data/players.js` — база футболистов, позиции и данные для карточек.
- `js/data/gameplay.js` — формации, игровые стили, позиции и настройки матчевой логики.
- `js/data/economy.js` — спонсорские контракты и их требования.
- `js/data/localization.js` и `js/data/v51-translations.js` — переводы интерфейса и устаревших текстовых ключей.
- `js/data/ui-config.js` — навигация и темы.
- `supabase/001`–`005` — облачные сохранения, мультиплеер, быстрые матчи, социальные функции, рынок и исправление флага повторных карточек.
- `assets/packs/` — изображения паков Агентства.
- `assets/match-actions/` — локальные иллюстрации игровых ситуаций.

## Основные данные

Сохранение хранится в `zeroFootball.save.v1`. Данные клуба находятся в `db.clubs`; активный клуб определяется `db.activeClubId`. Не удаляй и не переименовывай ключи сохранения без миграции совместимости.

Карточки, выставленные на обмен или трансферный рынок, временно исключаются из доступного состава. Повторные карточки помечаются `marketResaleOnly` и могут быть только перепроданы. В Supabase за перенос и статус карточек отвечают RPC-функции из SQL-миграций.

## Экономика

`marketValue(rating)` задаёт оценочную стоимость карточки в миллионах евро. `saleRange()` показывает нижнюю и верхнюю границы продажи, а `randomSalePrice()` выбирает фактическую сумму внутри диапазона. Деньги внутри игры выражены в миллионах евро.

Промокод v67: `Reliz` — однократно выдаёт €50 млн и два трёхзвёздочных пака. Задания используют прогресс клуба и активные спонсорские множители.

## Запуск и обновление

Для локального запуска используй `python -m http.server 8000`, затем открой `http://localhost:8000`. Для существующей установки v66 после миграций `001`–`004` выполни только `supabase/005_v67_market_economy_fix.sql`.

Не отключай RLS и не размещай серверный секрет Supabase в клиентских файлах.
