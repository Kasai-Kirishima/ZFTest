# Карта архитектуры Zero Football v25

## Порядок загрузки

1. `index.html` загружает CSS в нумерованном порядке.
2. `js/data/players.js`, `gameplay.js`, `localization.js`, `ui-config.js`, `economy.js` добавляют константы в `window.ZF_DATA`.
3. `js/app.js` читает эти значения в исходное замыкание игры и запускает приложение.

## Границы модулей

| Область | Файл | Что туда относится |
|---|---|---|
| Игроки и страны | `js/data/players.js` | Реальные игроки, национальности, фотографии, позиции |
| Футбольные правила | `js/data/gameplay.js` | Игровые позиции, схемы, стили, боты, достижения |
| Переводы | `js/data/localization.js` | Переводы всех экранов и матчевых событий |
| Настройки UI | `js/data/ui-config.js` | Пункты меню, темы оформления |
| Экономика | `js/data/economy.js` | Предложения спонсоров |
| Логика | `js/app.js` | Состояние, сохранение, экраны, матчи, события и действия |
| Внешний вид | `css/*.css` | Базовые стили и последующие адресные переопределения |

`app.js` пока остаётся одним модулем логики, чтобы не менять внутренние связи и поведение игры при первой структурной миграции. Его можно делить на `core`, `squad`, `matches`, `market` и `ui` отдельным этапом, когда появятся тесты и устойчивые интерфейсы между модулями.
