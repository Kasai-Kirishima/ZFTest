# Zero Football v103

- Исправлен жизненный цикл экрана результатов открытия паков: перед новой отрисовкой удаляется предыдущий overlay, повторные экземпляры экрана не накапливаются.
- При показе результатов блокируется прокрутка страницы под overlay; при закрытии и переходе к другому экрану блокировка снимается.
- Для пакетного открытия используется единая flex-компоновка: верхняя информация и кнопки остаются на местах, сетка занимает только доступную нижнюю область.
- Старая сетка и новые правила больше не спорят за позиционирование карточек: все карточки размещаются по строкам, с отдельной прокруткой внутри сетки.
- После каждой новой отрисовки прокрутка результатов сбрасывается в начало.
- Игровая логика выпадения, карточки, экономика и существующие сохранения не менялись.
