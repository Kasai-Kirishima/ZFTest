# Zero Football v106

- Все паки Агентства доступны с самого начала независимо от уровня клуба. Ограничение ежедневного бесплатного пака (один раз в сутки) и проверка достаточности средств сохранены.
- Убран текст и блоки о разблокировке паков по уровням.
- Для стартовых футболистов добавлена предоставленная пользователем заглушка-портрет. Если внешний источник изображения недоступен, остаётся резервный SVG-аватар.
- Эмблемы используют единый пропорциональный размер слоёв относительно ширины самой эмблемы. Масштабирование применяется в редакторе, превью, меню, матчах и на мобильных устройствах.
- Старое сохранение `zeroFootball.save.v1` не меняется.
