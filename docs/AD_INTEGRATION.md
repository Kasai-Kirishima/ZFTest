# Рекламная интеграция Zero Football

В клиенте предусмотрен интерфейс для rewarded-рекламы через `window.ZF_AD_PROVIDER.showRewardedAd(options)`. Награда начисляется только при `result.completed === true`; закрытие или ошибка не дают матч.

**Реальные показы пока не активированы.** Для подключения нужны аккаунт издателя, одобренный рекламной сетью сайт/домен, её SDK и идентификаторы рекламного блока. Без этих данных нельзя безопасно встроить рабочую рекламу или проверить показы. Не подставляйте случайные publisher ID.

Адаптер должен вернуть Promise с объектом `{ completed: true }` после подтверждённого просмотра. Запрос в игре: `placement: 'energy_refill'`, `reward: { energy: 1 }`. Подключать SDK и реализовать адаптер нужно по документации выбранной сети.
