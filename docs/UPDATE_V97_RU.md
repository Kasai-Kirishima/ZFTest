# Обновление Zero Football v97

## Результаты матчей
- В блоке «Твои результаты» добавлена отдельная строка «Пропущено голов».
- Используется уже существующее поле `club.stats.goalsAgainst`; пересчёт и миграция старых сохранений не нужны.
- Подписи для забитых и пропущенных голов добавлены для поддерживаемых языков.

## Карточки результатов паков
- Последним стилем закреплена вертикальная пропорция 3:4 для карточек открытия паков.
- Вложенная карточка растягивается по размеру внешнего блока, фотография занимает гибкую центральную область.
- Для новых CSS/JS ресурсов добавлены версии в URL, чтобы браузер не продолжал использовать старый кэш.

## Вероятности Агентства
- Диапазон доступного рейтинга расширен до 99 OVR во всех наборах, включая ежедневный бесплатный.
- Вероятность диапазона 90+ теперь больше нуля для каждого типа пака:
  - Ежедневный бесплатный — 0,02% на карточку.
  - ★ — 0,05%.
  - ★★ — 0,2%.
  - ★★★ — 0,6%.
  - ★★★★ — 1,5%.
  - ★★★★★ — 3,5%.
- Все распределения складываются в 100%; дорогие паки сохраняют ощутимое преимущество.

## База футболистов
- Обновлены рейтинги и позиции Берке Озера (82), Матеуса Куньи (80), Конрада Лаймера (90) и Елиота Андерсона (85).
- Рейтинг Килиана Мбаппе оставлен на 91 OVR.
- Добавлены Фабиан Руис, Жуао Невеш, Алексей Батраков, Анастасиос Дувикас, Виктор Ёкерес, Йоакин Сейс, Ян Беднарек, Юлиан Риерсон, Златко Трипич, Каспер Пауль Молгард Йоргенсен, Арчи Браун, Жоау Канселу, Ян Бисек и Едуарду Фелисиму.
- Добавлены позиции и прямые ссылки на фотографии из предоставленного списка. Для прочих игроков сохранён текущий механизм загрузки изображений.

## Совместимость
- Формат `zeroFootball.save.v1` и структура облачных сохранений не менялись.
- Новые футболисты добавлены в конец базы: существующие ID записей базы не сдвигаются.
