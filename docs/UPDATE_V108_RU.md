# Zero Football v108

- Иллюстрации ключевых событий теперь сохраняются в хронике на экране итогов матча, а не только в live-экране.
- Для итогового протокола используется imageKey события; для старых/неполных записей добавляется попытка определить изображение по тексту события.
- Три лучшие карточки соперника принудительно остаются в одной строке на мобильных экранах; размеры внутренних элементов адаптируются к ширине карточки.
- Остальная логика матчей и сохранений не менялась.
