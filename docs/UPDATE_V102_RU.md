# Zero Football v102

- Для открытия нескольких паков добавлена отдельная полоса прокрутки результатов над сеткой карточек.
- Сетка расположена отдельным нижним блоком с собственным вертикальным скроллом; количество карточек больше не сжимает и не накладывает соседние ряды.
- Ползунок синхронизирован с прокруткой сетки: можно прокручивать карточки колёсиком, свайпом или перетаскиванием ползунка.
- Уменьшено вертикальное смещение анимации карточек в пакетном открытии, чтобы соседние ряды не пересекались во время появления.
- Обычное открытие одного пака сохранено без изменений.
