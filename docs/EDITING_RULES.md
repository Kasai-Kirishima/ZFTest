# Порядок работы с будущими изменениями

- Одна задача — один ограниченный участок. Изменение переводов не должно переписывать расчёт рейтинга; изменение CSS не должно менять данные сохранений.
- Перед правкой зафиксируй исходную версию файла и делай изменения поверх последней рабочей версии.
- Сначала меняй данные в `js/data/`, если требуется добавить игрока, клуб, стиль, тему, перевод или спонсора.
- Сначала меняй один файл CSS, если проблема только визуальная. Не добавляй очередной огромный inline-style в `index.html`.
- Меняй `js/app.js` только для поведения/логики. Ищи все места, где используется затронутая функция или поле объекта.
- После правки проверяй `node --check` для всех JS-файлов и запускай игру в браузере. Синтаксическая проверка не заменяет проверку игровых сценариев.
- Не меняй формат localStorage без миграции старых сохранений.
- Выпускай новую версию с обновлённым `CHANGELOG.md`; ZIP должен включать всю структуру проекта, а не только `index.html`.
