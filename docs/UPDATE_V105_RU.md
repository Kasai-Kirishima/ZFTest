# Zero Football v105

- Убран отдельный ползунок прокрутки карточек в результатах открытия нескольких паков.
- Все карточки отображаются в одной общей сетке с автоматическим добавлением новых строк.
- Количество колонок при пакетном открытии теперь совпадает с количеством колонок при открытии одного такого же пака; дополнительные паки добавляют строки, а не растягивают карточки по-другому.
- Прокручивается единый экран результатов по вертикали, а не отдельная внутренняя область с игроками.
- Блоки повторных карточек также включены в общий поток страницы без отдельной внутренней прокрутки.
- Сохранены визуальный стиль карточек, пропорции портретов 3:4, анимация, экономика, цены паков и расчёт продажи игроков из v104.
