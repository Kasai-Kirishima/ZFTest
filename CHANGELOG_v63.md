# Zero Football v63

- Повторная карточка снова продлевает контракт соответствующего игрока на 5 дней.
- Покупка паков отделена от открытия: приобретённые наборы попадают в отдельный инвентарь.
- Добавлен выбор количества покупаемых паков (1, 2, 3, 5 или 10).
- Пак открывается только из инвентаря; после открытия списывается одна единица.
- Добавлен промокод `1OnlinTest`: по одному паку каждого типа, один раз на клуб.
- Ежедневный магазин показывает три карточки; каждую можно приобрести один раз за день. Смена ассортимента происходит по локальной дате в 00:00.
- В хронике матчей убраны технические детали бросков и модификаторов, оставлен текст игрового эпизода в формате комментария.
