# Обновление Zero Football v96

## Что добавлено
- В разделе статистики матчей показывается общее количество пропущенных клубом мячей.
- В отчёте о матче отдельно отображается число пропущенных мячей в текущей игре.
- Данные берутся из существующих `club.stats.goalsAgainst` и `m.score[1]`.

## Установка
Замените файлы проекта содержимым архива v96. Конфигурацию `js/supabase-config.js` сохраняйте без изменений.

Новая миграция Supabase не нужна: счётчик пропущенных голов уже сохранялся предыдущими версиями игры. Старые записи не пересчитываются и не теряются.
